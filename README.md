# ValAgent

סוכן AI בעברית בכיס שלך. צ'אט מלא בעברית שמתחבר לכל ספק תואם OpenAI
(NVIDIA NIM כברירת מחדל), מתחבר לשרת **MCP** (Streamable HTTP), מריץ **כלים**
מהשרת ומציג כל קריאה ותוצאה ככרטיס מסודר בתוך השיחה.

## יכולות
- צ'אט עברי RTL עם תשובות סטרימינג חיות (SSE)
- כרטיסי כלים: פרמטרים, סטטוס (מריץ/הושלם/נכשל) ותוצאה מתקפלים
- הגדרות: כתובת בסיס API, מפתח API, מודל, כתובת שרת MCP, טוקן אימות
- בדיקת חיבור MCP בלחיצה + מחוון מצב בכותרת
- מצב כהה/בהיר/מעקב מערכת, ניקוי צ'אט, עצירת תשובה

## התקנה
1. הורד את ה-APK מ-Actions/Releases של הריפו
2. אפשר "התקנה ממקורות לא ידועים" לדפדפן פעם אחת
3. התקן ופתח → הגדרות → הזן מפתח API (ו-שרת MCP אם יש)

## בנייה
Push ל-main מפעיל GitHub Actions שמייצר `app-debug.apk` ומעלה אותו ל-Releases.
